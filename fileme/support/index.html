Reporting an issue

Please include:

  • Your macOS version and Mac model.
  • The FileMe version shown in Settings → About.
  • The steps that led to the issue, what you expected and what happened.
  • Whether it involves a local folder, an external drive or a remote connection.

A screenshot can help. Hide private filenames, account details and other sensitive information before sharing it. Do not send passwords, private keys or confidential files.

Optional diagnostic log

In FileMe, open Settings → Diagnostics, select FileMe.log and choose Save log… to review a copy. Send log… opens a Mail draft; you decide whether to send it. Logs are not automatically uploaded to the developer. Review the attachment before sharing it.

Folder access and remote connections

If a folder cannot be opened, check Settings → Privacy → Folder access and select the intended folder using the macOS chooser. An external drive must be connected and the folder must permit the requested operation.

For a remote connection issue, check the server address, protocol, credentials and network connection. FileMe's Offline mode blocks its own remote connections. Do not include credentials in a support request.

Your information

FileMe does not automatically send your files or browsing activity to the developer. If you contact support, your message and the attachments you choose to send are used to handle your request. Read the FileMe Privacy Policy for details.
